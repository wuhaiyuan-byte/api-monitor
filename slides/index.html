04

核心功能

🐌 延迟监控

实时追踪 API 响应时间，智能检测性能异常（3σ 原则）

📈 状态码监控

验证预期状态码，自动标记异常状态

✅ 内容校验

支持正则表达式匹配响应内容，确保数据正确性

🔌 WebSocket

实时推送监控状态，秒级响应无需轮询

📧 邮件告警

SMTP 邮件通知，告警及时送达

🎨 Bruno 风格

直观的请求配置界面，支持 Params/Headers/Body/Auth
